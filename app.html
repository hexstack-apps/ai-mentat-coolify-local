Coolify Local Setup

Checking current state… showing the last confirmed status until the VM answers.

Step 1 — Lima VM (Docker host)

On macOS the Coolify stack runs inside a bundled Lima VM (Apple Virtualization.framework). On Linux a local Docker daemon is used directly when Lima is not available.

Step 2 — Install Coolify

Runs the official https://cdn.coollabs.io/coolify/install.sh inside the VM. The script installs Docker and bootstraps the Coolify docker-compose stack. This can take several minutes on first run.

Step 3 — Start / Stop Coolify

Brings the Coolify stack up or down via docker compose. Start once and leave it running — Coolify hosts long-lived applications.

        What is Coolify and how does this app wrap it?
        

          
Coolify is an open-source, self-hosted platform-as-a-service — think Heroku/Vercel running on your own machine. It deploys apps, databases, and services from Git as Docker containers.

          
This app runs the Coolify stack locally for you: on macOS it spins up a bundled Lima VM (Apple Virtualization.framework, no Docker Desktop required), then runs Coolify's official install.sh inside. The UI you see in the first tab is the real Coolify web interface served at http://localhost:8000.

          
Use the Setup tab to create the VM and install Coolify the first time. Use the Cloudflare Tunnel tab to expose Coolify (and optionally SSH) to the public internet without opening router ports.

        SSH deployments and "different connections" tunneling
        

          
Coolify manages remote servers over SSH. Two related tunneling flows are supported from the Cloudflare Tunnel tab:

          
    
            
  • HTTP tunnel — exposes the Coolify UI (port 8000) under a public hostname. Use this to access the dashboard from anywhere.
    • 
            
  • SSH tunnel — exposes the VM's SSH daemon (the VM's :22, host-forwarded to :2222) under a separate hostname. Connect with ssh -o ProxyCommand="cloudflared access ssh --hostname %h" user@ssh-coolify.example.com. This lets you git-push deployments or run Coolify-side commands without exposing your home network.
    • 
          

          
Outbound SSH from Coolify to remote servers you manage is handled by Coolify itself (Configuration → Servers in its UI).

        

      


      

        Where is Coolify data stored? Does uninstalling the app delete it?
        

          
All Coolify data — database, deployment configs, SSH keys it generates, app build artefacts — lives inside the Lima VM at /data/coolify. The VM itself lives at ~/.coolify-lima/.

          
Deleting the Mentat app does not delete the VM. To fully remove Coolify: stop it from the Setup tab, then remove the VM with limactl --tty=false delete -f coolify and delete ~/.coolify-lima/.

        

      


      

        Port conflicts — Coolify refuses to start
        

          
Coolify binds 8000, 6001, 6002, 8080, and 2222 on the host. If any of those are in use (e.g. another dev server), stop the conflicting process and retry. On macOS, lsof -iTCP -P -n | grep LISTEN will show what's holding the port.
